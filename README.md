# TBD-Taikisha Landing Page

A modern landing page for TBD-Taikisha, built with [Next.js](https://nextjs.org), [Tailwind CSS](https://tailwindcss.com), and TypeScript.

## Pages

- **Home** — Hero section, company stats, services overview, and CTA
- **About** — Company story and values
- **Services** — Detailed service offerings (Environmental Systems, Paint Finishing, Industrial Infrastructure, Maintenance)
- **Contact** — Contact form and company information

## Getting Started

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Tech Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Geist Font
